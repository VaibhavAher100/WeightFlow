## Decisions Made

1. **Debug builds skip SQLCipher** — EncryptedSharedPreferences Keystore init blocks main thread for 30-55s. Release builds still encrypt. Debug builds use plain Room.
2. **OSV scan uses reusable workflow** — Direct Docker action (`osv-scanner-action/osv-scanner-action@sha`) is documented as "not intended for direct use." Switched to `/.github/workflows/osv-scanner-reusable.yml` which handles SARIF internally.
3. **`onboardingState` emits `false` for absent key** — Original implementation emitted `null` for absent key, which mapped to permanent black screen. `false` = "key absent = onboarding not done" is correct semantics.
