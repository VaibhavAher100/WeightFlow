## Decisions Made

1. **LogEntry as ModalBottomSheet state (not navigation destination)** — FAB sets `showLogEntry = true` in ShellScreen; ModalBottomSheet overlays content. Navigation-based bottom sheets are awkward in Compose Navigation and cause background content issues.

2. **HomeDataAggregator as interface** — testable without mocking concrete class. Fake implementations via anonymous objects in tests.

3. **`awaitRealState()` helper pattern** — `stateIn(WhileSubscribed)` always emits `Loading` as first item before upstream coroutine runs. All ViewModel tests skip the initial Loading item with a helper.

4. **OnboardingViewModel step FSM** — `onNextStep()` is synchronous (pure `MutableStateFlow.update`), `onComplete()` launches coroutine. Tests call `navigateTo()` as a plain non-suspend helper.

5. **TrendsScreen Vico wiring deferred** — `ChartView` shows metadata (min/max/count) but no actual Vico chart yet. Wiring Vico is the next task in Phase 2.
