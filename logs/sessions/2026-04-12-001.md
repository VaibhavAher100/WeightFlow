## Design Decisions Made

### Visual Design
- **App name:** WeightFlow
- **Aesthetic:** "Athlete's Journal" — warm dark base (#0F0E0B), electric lime accent (#C8FF00)
- **Typography:** Bebas Neue (all weight numbers), Outfit (all UI text)
- **5 screens in mockup:** Home, Trends, Log Weight, Profile, Settings
- **8 accent colors:** Lime, Coral, Cyan, Pink, Violet, Yellow, Mint, Red (user-selectable)
- **Bottom nav:** 5 tabs — Home, Trends, Log (+FAB), History, Profile; Settings via Profile

### Architecture Decisions
- **DI approach:** Manual DI via Application class (no Hilt — simpler for solo dev)
- **State:** `StateFlow` + `collectAsStateWithLifecycle()` throughout
- **ViewModel pattern:** Each screen owns exactly one ViewModel
- **History tab:** Added to bottom nav (replaced Settings tab there); Settings accessed via Profile
- **Chart library:** Vico 1.13.1 (`compose-m3`) — confirmed working in Trends + sparkline
- **DataStore:** Preferences via `UserPrefsDataStore` wrapper (accent, dark/pro mode, units)
