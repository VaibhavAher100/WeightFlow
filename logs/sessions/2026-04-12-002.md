## Decisions Made

### Product Strategy (Locked)
- **Revenue**: Free core forever + $2.99 one-time Pro unlock + Ko-fi/Liberapay donations + small AdMob banner (free users only)
- **iOS**: Android first → TestFlight beta free → BuyMeACoffee funds $99 Apple account → KMP for shared codebase
- **CSV import/export**: Free for everyone (data portability = trust + growth)
- **Fasting timer**: Phase 6+ roadmap item (Zero competitor, same app, free)
- **Languages**: English + German at launch, Hindi Phase 3, community translations via Crowdin

### Privacy (Locked)
- On-device storage satisfies GDPR/CCPA/PIPL core requirements by architecture
- AdMob requires consent dialog before loading (GDPR)
- COPPA age gate (13+) required in onboarding
- China: offline-only mode (Firebase blocked)
- Privacy policy must be live URL before Phase 4 (use GitHub Pages)

### Environment (Locked)
- **Working directory**: Always open `WeightFlow/` — never `102/` root
- **Agent scope**: Project-local only (18 agents in `WeightFlow/.claude/agents/`)
- **Convention**: Conventional Commits, SemVer, ADR in `docs/adr/`, GitHub Actions CI
- **Business research**: Separate in `business/` — no crossover
