## Decisions Made

- **Age gate threshold raised to 18+** globally (not region-gated to India). Simpler code path; DPDP §14 requires parental consent for under-18, COPPA requires 13+. One global 18+ gate covers both with a single code path. Filed as locked decision.
- **Year-of-birth picker replaces checkbox**: FTC guidance says a binary "I am 13+" checkbox is not a neutral age gate because children learn to click it. A year-of-birth input prevents bypass — the Next button stays disabled unless the calculated age ≥ 18.
- **Donation links in ProfileScreen for now**: Settings screen is in main (merged via PR #30) but doesn't have an "About" section yet. Adding to ProfileScreen as interim; will move to Settings→About when that section is built.

## Reasoning

- ProGuard rules written conservatively: keep all domain/data classes (Room entities) to prevent R8 stripping fields used only via reflection. Vico kept fully because it uses internal reflective access to its own entry model.
- Signing config uses `local.properties` (git-ignored) rather than env vars — consistent with Android Studio conventions and what developers expect when cloning the repo.
- Year-of-birth picker uses `LocalDate.now().year` (API 26+, we target API 26) — no need for Calendar.
- `clearAllPreferences()` uses `dataStore.edit { it.clear() }` — atomic clear of the entire preferences store, not piecemeal removal. This ensures a clean slate on "delete all".
- Delete confirmation dialog uses `rememberSaveable` so it survives configuration changes.
