## Decisions Made

**Vico API discovery method:** context7 docs returned v3.x (CartesianChartHost, CartesianChartModelProducer) but we are on 1.13.1. The correct approach for locked older library versions is to read the actual source JARs from the Gradle cache rather than relying on docs tools.

**Onboarding gate `initialValue = true`:** Prevents a brief flash of OnboardingScreen while DataStore loads on cold start for users who have already completed onboarding. New users see a momentary ShellScreen flash instead — acceptable trade-off (ShellScreen shows a loading spinner anyway).

**`OnboardingViewModel` constructed in `MainActivity.onCreate`:** Not in a `remember {}` block — intentional. The ViewModel lives for the duration of the Activity and DataStore navigation is one-shot. Using `viewModel()` factory would require Hilt or ViewModelFactory boilerplate we don't want; manual construction matches the project's DI approach.

## Reasoning

Vico 1.13.1 uses `Chart` composable + `ChartEntryModelProducer.setEntriesSuspending()` + `FloatEntry(x, y)`. This is completely different from the v2/v3 API that context7 and most internet docs describe. Key imports: `com.patrykandpatrick.vico.compose.chart.Chart`, `com.patrykandpatrick.vico.compose.chart.line.lineChart`, `com.patrykandpatrick.vico.compose.axis.vertical.rememberStartAxis`, `com.patrykandpatrick.vico.compose.axis.horizontal.rememberBottomAxis`, `com.patrykandpatrick.vico.core.entry.ChartEntryModelProducer`, `com.patrykandpatrick.vico.core.entry.FloatEntry`.

OnboardingScreen uses conditional rendering on `currentStep` enum rather than HorizontalPager — simpler, no animation needed, avoids the complexity of pager state management for a one-time flow.
