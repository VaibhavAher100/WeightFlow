## Decisions Made

- **Settings gear icon placement:** Top-right of Profile `PageHeader` row (matches "Profile" title left, gear right pattern). No TopAppBar used — consistent with existing Profile layout.
- **CSV export architecture:** VM emits `ExportCsvReady(csv: String)` → Screen stores in `remember` state → launches SAF `CreateDocument` → writes via `ContentResolver` on URI return. Keeps VM Android-free and fully testable.
- **Haiku worker permission issue:** Haiku workers hit write permission wall in this session config. Pattern for future: brief workers for analysis/read, let Executor (Sonnet) do all writes.
