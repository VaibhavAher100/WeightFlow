## Decisions Made

1. **Room upgraded 2.6.1 → 2.7.0** — Room 2.6.1 is not KSP2-compatible. Two distinct bugs: (1) KSP2 fails to resolve `Unit` JVM signature (`V`) during annotation processing; (2) generated Java impl uses `Continuation<T>` instead of `Continuation<? super T>`, breaking `@Override`. Room 2.7.0 fixes both. `ksp.useKSP2=false` is NOT a valid workaround for AGP 9.x — it breaks variant resolution.

2. **`@Delete` returns `Int`, `@Upsert` returns `Long`** — avoids the KSP2 void signature bug AND produces a strictly better API (rows deleted / row ID). Kept after the Room upgrade as a deliberate improvement.

3. **`UserPrefsDataStore` takes injected `DataStore<Preferences>`** — avoids Context dependency in production code and makes the class trivially testable. Application class will create and inject the DataStore singleton using `preferencesDataStore` delegate.
