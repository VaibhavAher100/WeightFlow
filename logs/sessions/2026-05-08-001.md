## Decisions Made

- **Zero/Whoop-inspired "Ritual Entry" design language** — number is the hero, drum-roll picker, underglow, coaching sentences (Whoop pattern), full-pill CTA (Zero pattern)
- **Approach C (Hero Moments → System → Remaining Screens)** — log entry, home progress, goal achieved defined first; design language extracted; remaining screens follow
- **Drum-roll picker over keyboard input** — replaces BasicTextField entirely; no fallback keyboard
- **Single accent voice** — lime used max 2× per screen per Impeccable One Voice Rule
- **accentSoft/accentBorder helpers** — added to WFTokens for consistent tinted surfaces
- **`WheelPicker` custom composable** — built with `LazyColumn` + `rememberSnapFlingBehavior`; no third-party picker library
- **`WFHaptics` with `launchIn` pattern** — LogEntryViewModel uses `WhileSubscribed(5_000)` + `uiState.launchIn(viewModelScope)` to seed combine in test context
- **Task 11 was already implemented** — Settings theme grid existed from prior session; Sonnet agent confirmed and skipped re-implementation
- **Haiku workers cannot write files** — confirmed per CLAUDE.md; Task 11 Haiku agent was re-dispatched as Sonnet
