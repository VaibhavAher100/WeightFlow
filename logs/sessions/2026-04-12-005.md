## Decisions Made

1. **Nav is 4 tabs + FAB** (not 5 tabs). Log is a FAB bottom sheet, not a dedicated tab.
2. **Home uses always-full layout with motivating empty states** (not data-gated reveal).
3. **Log sheet: weight + date only** (no note field). Correlation feature dropped.
4. **Goals: FSM** (active to reached to maintenance, with option to chain new goal at completion).
5. **Badges: 12 total** (Zero-inspired: First Steps / Streaks / Volume / Progress / Resilience / Maintenance).
6. **Pro: 4.99 EUR one-time, contextual discovery only**. No persistent CTA anywhere.
7. **Revenue: donations first** (Ko-fi / Liberapay / GitHub Sponsors), Pro second. Marketed as free.
8. **CSV import: all 4 formats** at launch (WeightFit + Happy Scale + Apple Health + generic).
9. **Charts: Line + Bar + Area + Candlestick**. Time filters: 7D / 30D / 3M / 6M / 1Y / All.
10. **RTL-safe from Phase 2** (start/end semantics, no left/right hardcoding).
11. **Repo private for now**, rename before launch.
12. **All weights stored in kg internally**. Unit conversion is display-only, never stored.
13. **BadgeObserver**: reactive (combine Room Flows), not imperative (called on insert).
14. **CsvImporter**: single entry point with CsvFormat enum surfaced in ParseResult.
15. **GoalStateMachine**: explicit sealed class FSM with transition functions.
16. **StoredWeight** value class for Room + HomeUiStateMapper for single conversion point.
17. **SortedEntries** wrapper type + named ordering methods on Repository.
18. **HomeDataAggregator**: ViewModel gets one dependency instead of five.

## Reasoning

The skill sequence was designed to front-load all product thinking before writing a line of code. grill-me surfaced 21 decisions that would otherwise have caused rework mid-implementation. The PRD locks those decisions in a testable form (user stories as acceptance criteria). prd-to-issues converts the PRD into independently executable vertical slices so each can be picked up and merged without coordination. TDD pre-writes the failing tests so the RED step is done before the Android project even exists. improve-codebase-architecture catches architectural seams in the planned design before they become bugs in production code. The 6 RFCs are now GitHub issues that Phase 1 implementors will reference when wiring modules together.
