## Decisions Made

- **LogEntry unit toggle is display-only**: The VM reads unit from DataStore but has no `onUnitSelected` method. Adding one would require a new test. Since unit is set in Settings/Onboarding, displaying the current unit as a non-interactive segmented indicator is correct behavior.
- **BasicTextField for weight number**: Used `BasicTextField` with Bebas Neue 72sp textStyle + decorationBox placeholder ("0.0"). Allows both keyboard entry and +/- step buttons. Cleaner than hidden overlay approach.
- **OnboardingScreen branding**: Added "WEIGHTFLOW" in Bebas Neue 48sp accent + "TRACK · REFLECT · IMPROVE" tagline at top. Matches Athlete's Journal identity. Not in original mockup (no onboarding mockup exists) but consistent with other screens.
- **Step dots with pill indicator**: Active step = 24dp wide accent pill, past = accent 40% alpha 8dp, future = grey 30% alpha 8dp. More visual than plain "Step N of 4" text.
