# WeightFlow — TDD Execution Order

_The RED step is already done for domain modules. Tests live in `app/src/test/java/com/weightflow/domain/`._
_Follow this order exactly. Never write production code before a failing test exists._

---

## The Iron Law

```
NO PRODUCTION CODE WITHOUT A FAILING TEST FIRST
```

If you write code before a test: delete it. Start over.

## Rules (Non-Negotiable)

1. **Run the failing test before writing production code.** If you can't show it fails, you haven't started TDD.
2. **One test at a time.** Write one test, watch it fail, implement minimal code, watch it pass, repeat.
3. **Minimal implementation.** Don't implement features the test doesn't require.
4. **All tests stay green.** Never proceed with a broken test suite.
5. **Refactor after green only.** Never refactor while red.
